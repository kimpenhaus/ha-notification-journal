# Security policy

## Supported versions

Only the latest release gets fixes.

## Reporting a vulnerability

Please report security issues privately through GitHub: *Security → Report a vulnerability* on this repository. Do not open a public issue for them.

Include what an attacker could do, the steps to reproduce it and the version. You get an answer within a week; a fix is released as soon as it is ready, and the advisory is published after that.

Notification Journal stores the notifications your home sends. Issues that expose them to users who should not see them, or let a user change what others see, count as security issues.
